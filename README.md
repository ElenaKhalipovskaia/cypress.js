## Описание проекта и задачи
Автоматизировать часть проверок регресса с помощью Cypress: авторизация и восстановление пароля на форме входа.

## Что проверяется

Всего 6 автотестов.

| № | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| 1 | Верный логин и верный пароль | Сообщение «Авторизация прошла успешно» |
| 2 | Верный логин и неверный пароль | Сообщение «Такого логина или пароля нет» |
| 3 | Неверный логин и верный пароль | Сообщение «Такого логина или пароля нет» |
| 4 | Невалидный логин (без «@») и верный пароль | Сообщение «Нужно исправить проблему валидации» |
| 5 | Логин в верхнем регистре и верный пароль | Логин приводится к нижнему регистру, сообщение «Авторизация прошла успешно». **Тест падает: в приложении баг, приведения к нижнему регистру нет** |
| 6 | Восстановление пароля с верным логином | Сообщение «Успешно отправили пароль на e-mail» |

Общие проверки для всех тестов (хуки):
- `beforeEach`: открыть сайт и проверить цвет кнопки «Забыл пароль»;
- `afterEach`: проверить, что виден значок закрытия окна с результатом.

## Детали реализации

1. `baseUrl` вынесен в конфиг (`cypress.config.js`), в тестах используется `cy.visit("/")`.
2. Применяются хуки `beforeEach` и `afterEach`.
3. Верные данные для авторизации вынесены в отдельный файл `cypress/helpers/default_data.json`. Неверные значения заданы прямо в негативных тестах, потому что они специфичны для каждого сценария.
4. Каждая страница описана в формате объекта с локаторами (`cypress/locators/`), при изменении селектора правка делается в одном месте.

## Структура проекта

```
cypress/
  e2e/
    tests.cy.js                  # автотесты
  locators/
    main_page.json               # локаторы страницы авторизации
    recovery_password_page.json  # локаторы страницы восстановления пароля
    result_page.json             # локаторы окна с результатом
  helpers/
    default_data.json            # верный логин и пароль
cypress.config.js                # baseUrl, размер окна, блокировка аналитики
```

## Локальный запуск тестов

1. Скачать проект и открыть в терминале папку проекта.
2. Установить зависимости:
```
npm install
```

### Запуск из терминала
```
npx cypress run --spec cypress/e2e/tests.cy.js --browser chrome
```
Ожидаемый результат: 5 тестов проходят, тест №5 падает из-за бага в приложении.

### Запуск через Cypress UI
1. В папке проекта выполнить `npx cypress open`.
2. Выбрать E2E Testing и браузер Google Chrome.
3. Выбрать спеку `tests.cy.js`.

Ожидаемый результат: 5 тестов проходят, тест №5 падает из-за бага в приложении.
